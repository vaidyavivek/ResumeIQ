# ResumeIQ 🔍

An AI-powered resume analyzer that gives you an ATS score, keyword analysis, bullet rewrites, and a cover letter — in seconds.

🚀 **[Live Demo](https://resumeiq-nxomduynt7gxxdhlaqp5dv.streamlit.app)**

## Features

- 📊 **ATS Score** — see how your resume ranks (0-100)
- 🔑 **Keyword Analysis** — find missing keywords from the job description
- ✏️ **Bullet Rewrites** — before/after improvements to your resume bullets
- 🎤 **Interview Prep** — likely interview questions for your target role
- 📝 **Cover Letter Generator** — one-click personalized cover letter

## Tech Stack

- Python
- Streamlit
- OpenAI GPT-4o-mini
- PyPDF2
